# Snake Game 🐍

A classic Snake Game built using Python and Pygame.

## Features
- Snake movement using arrow keys
- Random food generation
- Score tracking and snake growth
- Increasing difficulty
- Wall and self-collision detection
- Start screen, pause, and restart
- High score saved in a file

## Technologies Used
- Python
- Pygame

## How to Run

Install Pygame:

```bash
python -m pip install pygame
```

Run the game:

```bash
python snake_game.py
```

## Controls
- Enter: Start
- Arrow keys: Move
- Spacebar: Pause or resume
- R: Restart after Game Over
